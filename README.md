# Z Works Painting, LLC - Official Website

A custom-built, responsive landing page for Z Works Painting, LLC, providing premier residential and commercial painting services across the Salt Lake Valley.

## 🚀 Project Overview

This website serves as the primary digital storefront for the business, showcasing over 10 years of professional painting experience. It is designed to act as a high-end digital brochure that establishes trust, highlights craftsmanship, and provides an easy way for local clients to request estimates.

## 🛠️ Built With

*   **HTML5:** Semantic structure for optimal accessibility and SEO.
*   **CSS3:** Custom styling utilizing CSS variables, responsive design principles, and modern layout techniques.
*   **Vanilla Web Technologies:** Zero external frameworks for blazing fast load times.

## 🌟 Key Features

*   **Custom Hero Section:** Impactful visual hook featuring authentic project photography.
*   **Service Highlights:** Clear, scannable breakdowns of residential and commercial offerings.
*   **Responsive Layout:** Adapts flawlessly to desktop, tablet, and mobile screens.
*   **Estimate Form:** Streamlined contact interface styled for intuitive user experience.

## 💻 How to Run Locally

To view this project on your local machine:

1. Clone this repository to your local computer.
2. Open the project folder in Visual Studio Code (or your preferred editor).
3. Right-click the `index.html` file and select **Open with Live Server** to view the active, auto-refreshing site in your browser. 
   *(Alternatively, simply double-click the `index.html` file to open it directly in any web browser).*
